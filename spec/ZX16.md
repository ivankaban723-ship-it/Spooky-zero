# ZX-16 architecture (v0.1)

A tiny 16-bit RISC-style CPU designed for the ZERO project.

## Machine

| Item | Value |
|---|---|
| Word size | 16 bits |
| Memory | 64 KiB, byte-addressable, little-endian, addresses wrap around |
| Registers | `r0`-`r7` (16-bit). `r7` is also called `sp`, the stack pointer |
| Program counter | 16-bit, starts at `0x0000` |
| Flags | `Z` zero, `N` negative, `C` carry/borrow, `V` signed overflow |
| Stack | grows downwards; `sp` starts at 0, so the first push writes to `0xFFFE` |
| I/O | `OUT` writes a byte to stdout, `OUTN` writes an unsigned decimal number |

The program binary is loaded at address 0 and execution starts there.

## Instruction encoding

Every instruction is exactly **4 bytes**:

```
byte 0      byte 1        byte 2-3
opcode      a(4) | b(4)   imm16 (little-endian)
```

`a` and `b` are register numbers (0-7). Unused fields are zero.

## Instruction set

| Opcode | Mnemonic | Operands | Effect | Flags |
|---|---|---|---|---|
| 00 | `nop` | | nothing | |
| 01 | `halt` | | stop the CPU | |
| 02 | `ldi` | `rd, imm` | `rd = imm` | |
| 03 | `mov` | `rd, rs` | `rd = rs` | |
| 04 | `add` | `rd, rs` | `rd += rs` | Z N C V |
| 05 | `sub` | `rd, rs` | `rd -= rs` | Z N C V |
| 06 | `and` | `rd, rs` | `rd &= rs` | Z N (C,V cleared) |
| 07 | `or` | `rd, rs` | `rd \|= rs` | Z N (C,V cleared) |
| 08 | `xor` | `rd, rs` | `rd ^= rs` | Z N (C,V cleared) |
| 09 | `shl` | `rd, rs` | `rd <<= (rs & 15)` | Z N (C,V cleared) |
| 0A | `shr` | `rd, rs` | `rd >>= (rs & 15)` (logical) | Z N (C,V cleared) |
| 0B | `addi` | `rd, imm` | `rd += imm` | Z N C V |
| 0C | `cmp` | `ra, rb` | flags of `ra - rb`, result discarded | Z N C V |
| 0D | `cmpi` | `ra, imm` | flags of `ra - imm`, result discarded | Z N C V |
| 0E | `ld` | `rd, [rs+imm]` | `rd = mem16[rs + imm]` | |
| 0F | `st` | `[rd+imm], rs` | `mem16[rd + imm] = rs` | |
| 10 | `ldb` | `rd, [rs+imm]` | `rd = mem8[rs + imm]` (zero-extended) | |
| 11 | `stb` | `[rd+imm], rs` | `mem8[rd + imm] = low byte of rs` | |
| 12 | `jmp` | `addr` | `pc = addr` | |
| 13 | `jz` / `je` | `addr` | jump if `Z` | |
| 14 | `jnz` / `jne` | `addr` | jump if not `Z` | |
| 15 | `jlt` | `addr` | jump if `N != V` (signed less-than) | |
| 16 | `jge` | `addr` | jump if `N == V` (signed greater-or-equal) | |
| 17 | `call` | `addr` | push return address, `pc = addr` | |
| 18 | `ret` | | pop `pc` | |
| 19 | `push` | `rs` | `sp -= 2; mem16[sp] = rs` | |
| 1A | `pop` | `rd` | `rd = mem16[sp]; sp += 2` | |
| 1B | `out` | `rs` | write low byte of `rs` to stdout | |
| 1C | `mul` | `rd, rs` | `rd *= rs` (low 16 bits) | Z N (C,V cleared) |
| 1D | `div` | `rd, rs` | `rd /= rs` (unsigned), error if `rs == 0` | Z N (C,V cleared) |
| 1E | `mod` | `rd, rs` | `rd %= rs` (unsigned), error if `rs == 0` | Z N (C,V cleared) |
| 1F | `outn` | `rs` | write `rs` as unsigned decimal to stdout | |

Memory operands accept `[rs]`, `[rs+expr]` and `[rs-expr]`.
An illegal opcode or a division by zero stops the emulator with an error.

## Assembly syntax

```asm
; comment
label:                  ; labels are just addresses
    ldi r1, 0x10        ; numbers: 10, 0x10, 0b1010, 'A', '\n'
    ldi r2, msg + 2     ; simple + and - expressions with labels
    .equ SIZE, 8        ; constant
    .byte 1, 2, 3       ; raw bytes
    .word 0x1234        ; 16-bit words (little-endian)
    .string "Hi\n"      ; bytes + terminating zero
    .ascii "Hi"         ; bytes, no terminator
    .space 16           ; 16 zero bytes
    .org 0x100          ; pad with zeros up to an address
```

Supported escapes in strings and characters: `\n \t \r \0 \\ \' \"`.

## Roadmap for the ISA

- memory-mapped screen and keyboard
- interrupts and a timer
- a second, wider encoding for long jumps (not needed while memory is 64 KiB)
